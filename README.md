# 質屋かんてい局 城陽店 プレオープンLP

2026年12月の城陽店オープンに向けた、出張買取キャンペーンのランディングページです。

## 開発

```bash
npm install
npm run dev
```

ローカル表示は `http://localhost:3000/` です。

## 確認

```bash
npm run build
npm test
```

`npm test` はメタ情報、検索公開設定、OGP、GTM、画像の代替テキスト、主要コンテンツを確認します。

## 公開用ファイル

`jyoyo-pre-lp/` の中身を、公開ドメインの `/jyoyo-pre-lp/` 配下へ配置します。
